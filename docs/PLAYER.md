# RhythmClicker 0.6 大更新測試版 · 第一版

開發：MoriTeahouse（森之宿茶室）。Windows x64 自包含版本可直接執行 ClickerGame.exe；初次啟動會生成三首原創示範曲。完整操作見 README.md。

D F J K 打擊，Space 暫停／繼續，Esc 返回，F11 全螢幕。Tab 換曲，左右換難度，上下選單。設定中 C 進入校正，跟拍 Space 至少八筆有效樣本後 Enter 套用；視覺偏移與判定偏移獨立。

預設資料在執行檔旁 UserData。指定 --data-root 完整路徑可將曲庫、統計、設定、帳號、重播與更新存於選定硬碟。備份整個資料目錄即可保留進度；既有 install_path.txt 仍有效。
